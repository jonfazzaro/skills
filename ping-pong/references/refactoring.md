# Refactoring

Refactoring is changing the form of code without changing its behavior. In ping-pong, the design step is a refactoring pass: the active agent strips code not required by current expectations, then cleans what remains.

## Relationship to ping-pong

- The design step in each ping-pong turn is a refactoring step
- The adversarial posture makes refactoring stricter — stripping unexercised code is required, not optional
- All expectations must stay green through every design change
