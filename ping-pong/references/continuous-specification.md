# Continuous Specification

Continuous Specification is a code design technique where each behavior is specified before it is implemented. Code is written in a tight cycle: set an unmet expectation (red), meet it with minimal code (green), then design/refactor while staying green.

Ping-pong pairing is a social structure built on top of this cycle — two agents alternate through it, with the adversarial posture enforcing the discipline that CS requires.

## Relationship to ping-pong

- Each ping-pong turn maps directly to a CS step: set expectation, meet it, design
- The adversarial design step enforces the CS discipline of stripping over-implementation
- Ping-pong cannot run without CS — the cycle is CS with roles assigned to agents
