# Working With Discovery Trees

Source: [Steve Kuo, “Working With Discovery Trees,” Industrial Logic](https://www.industriallogic.com/blog/discovery-trees/)

This skill adapts the article’s physical or virtual-whiteboard practice for coding conversations. The core ideas retained here are:

- make the feature’s state visible at a glance;
- start with a small story and allow the work to emerge through short conversations;
- use thin vertical slices and just-in-time planning;
- add newly discovered work instead of hiding it; and
- use the tree to preserve focus and make the work not done visible.

The article describes a flexible practice rather than a fixed process. The main skill specifies the conversation-oriented rendering conventions, the five-status palette, and next-task recommendations used in this workspace.
