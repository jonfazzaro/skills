# Pattern guide

## AIign on the Plan

Use before execution when the ensemble needs a common model of how people and
agents will work together.

1. Name the goal and the decision that signals completion.
2. Sketch the proposed workflow: contributors, prompts, tools, handoffs, and
   validation.
3. Have the ensemble identify assumptions, risks, and validation points.
4. Revise the workflow until its next action and ownership are clear.
5. Begin the agreed work.

Ask: “What must we agree on now so that parallel work remains coherent?”

## Plate Spinning

Use only after a longer-running agent task has actually started.

1. State what the running task is expected to return and what it cannot decide.
2. Assign useful parallel work that does not duplicate it: explore an edge case,
   define validation, inspect an adjacent boundary, or prepare the next prompt.
3. When the result returns, compare it with the parallel discoveries.
4. Decide what to keep, challenge, or iterate.

Ask: “What can we learn or prepare now that will make this result easier to
judge?”

## Assumptions First

Use when hidden context could send the work in the wrong direction.

1. Present the problem without asking for a solution.
2. Ask contributors to list assumptions, missing information, and questions.
3. Discuss which assumptions are safe, testable, or unacceptable.
4. Resolve or explicitly carry forward the important unknowns before solving.

Ask an agent: “Do not solve this yet. What assumptions are you making, what
information is missing, and what would you ask before proceeding?”

## AI 1-2-4-AIl

Use to preserve human-originated ideas before inviting AI critique.

1. Give everyone the same problem and a short independent thinking window.
2. Combine ideas in pairs, then in groups of four when the ensemble is large
   enough.
3. Share the strongest candidates with the full ensemble.
4. Ask AI to identify blind spots, risks, and alternatives in those candidates.
5. Decide together what changes the direction.

Keep AI in the critic role until the group has generated its own options.

## Quarantine & Combine

Use when competing approaches deserve independent exploration.

1. Define a common success criterion and constraints.
2. Give individuals or small groups distinct approaches, prompts, or tools to
   explore without sharing interim results.
3. Compare results against the shared criteria.
4. Identify the pieces that should survive.
5. Combine those pieces into a single next solution, then validate it.

Ask: “What did this approach reveal that the others may not have?”

## Role Cards

Use when a decision needs intentionally different lenses.

1. Choose only the roles that matter to the current decision, such as domain
   expert, implementer, reviewer, architect, tester, or user advocate.
2. Give each role the same decision and its bounded perspective.
3. Rotate or add a role only when it reveals a missing lens.
4. Compare the evidence, then decide as the ensemble rather than letting one
   role win by default.

Use roles as lenses, not as claims of real authority or expertise.

## Prompt Potluck

Use when the ensemble wants a better request before asking AI to act.

1. Give everyone the same problem and let each person draft a prompt.
2. Share drafts and identify valuable context, constraints, and differences.
3. Combine the strongest elements into one prompt.
4. Review it together for missing context and unwanted assumptions.
5. Run the refined prompt and judge its result together.

Ask: “What does this draft make visible that the others omit?”

## Transcript as a Prompt

Use when the group's existing discussion contains the needed context.

1. Let the ensemble discuss the problem naturally.
2. Capture the relevant transcript with consent and remove irrelevant or
   sensitive material.
3. Give AI a bounded task for the transcript: organize decisions, identify open
   questions, produce action items, or draft a proposal.
4. Review the result against what people actually said.
5. Correct the record and decide the next action together.

Never treat an AI summary as the conversation's source of truth.
